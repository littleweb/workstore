# WorkStore 0.1.16

设计室模板封面和示例图改为从GitHub按需加载，完整目录与提示词保留；图片校验后缓存，已缓存图片可离线显示。首次未缓存图片需要联网，加载失败支持点击或联网后重试。做封面的277张大预览同样采用按需缓存。

资源白名单与体积检查覆盖本机构建和正式发布，防止无用素材再次进入安装包。默认本机构建不要求更新私钥；发布沿用现有签名公钥，旧版本可通过原更新入口获取新版。

本次交付macOS Apple Silicon版本。482项前端与96项Rust单线程回归通过（5项联网/模型测试按约定忽略）；Windows、Linux、Intel Mac及Apple公证未验证。
