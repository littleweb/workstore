# WorkStore 0.1.17

做课程加入正式工具列表，提供知识卡片、白板沙画、动画教程和交互网页；包含十种视频风格与十二种交互网页风格参考。

课程参考图片、视频、试听和大型运行组件从公开GitHub固定版本按需加载，完整性校验后保存在本机缓存；已缓存资源可以离线使用。首次制作视频需要联网准备组件，网页在线发布才准备发布服务。用户无需安装开发环境。组件内的Python及Node依赖使用可迁移的相对链接，归档中的构建机路径和越界链接会阻断发布。

之前的安装包优化固化为发布前强制检查：只打包正式工具与白名单资源，阻断缺失页面、未声明资源及体积超限，检查版本、旧更新公钥、测试、签名与安装包完整性，CI使用同一正式构建入口。做封面与设计室继续按需加载素材。

macOS Apple Silicon安装包约53.4MiB，安装后约68.2MiB。504项前端与103项Rust单线程回归通过；5项外部联网/模型测试按约定忽略。

本次构建仅验证macOS Apple Silicon；Windows、Linux、Intel Mac、Apple公证、真实新主题模型生成与Vercel上传未验证。大型组件缓存会另外占用磁盘空间。
