# 白板应用

入口：WorkStore → 打开工具 → 白板（`app.whiteboard`）。点击右上角“创建”生成并打开新白板；默认名称“未命名白板”，可点击文档名称或列表菜单重命名。

左侧独立分为“常用”和“最近打开”。两组从同一份文档元数据派生，常用文档不重复出现在最近打开中。列表菜单可设为常用/取消常用、重命名、导出 JSON；最近打开条目也可拖进常用区域。最近按最后打开时间倒序。

右侧使用 Excalidraw 0.18.1，支持其画布绘图、文本、图片、缩放及撤销重做。每次切换文档重建画布，避免前一份文档的元素混入下一份；跨文档不共享撤销栈。Excalidraw 按需加载，字体从本地资源加载，不依赖字体 CDN。

## 本地文档类型

桌面版由 Rust 保存到当前工作目录：

```text
工作目录/
  data/app.whiteboard/<UUID>.whiteboard.json
  .workstore/whiteboard-backups/<UUID>.json
```

文件为 UTF-8 JSON，可直接备份。示意结构：

```json
{
  "type": "workstore.whiteboard",
  "schemaVersion": 1,
  "id": "UUID",
  "title": "我的白板",
  "favorite": false,
  "createdAt": 0,
  "updatedAt": 0,
  "lastOpenedAt": 0,
  "revision": 1,
  "scene": {
    "type": "excalidraw",
    "version": 2,
    "source": "WorkStore",
    "elements": [],
    "appState": { "viewBackgroundColor": "#ffffff" },
    "files": {}
  }
}
```

`scene` 由 Excalidraw 的 `serializeAsJSON` 生成，包含绘图元素、可持久化的画布设置和图片内容。图片以场景文件数据保存，不依赖原图片路径。标题与文件名解耦，重命名不会更改文档 ID。当前未注册操作系统文件关联，也未提供外部白板文件导入；恢复工作目录备份时保留 UUID 文件名。

## 保存与错误处理

- 修改后 650ms 防抖自动保存，每文档按顺序写入；保存期间继续编辑的内容会接着保存。
- 切换文档、切换工具、迁移工作目录、正常关闭窗口和退出前统一等待文档保存；保存失败时不执行这些切换操作。
- Rust 使用同目录临时文件和原子替换，并保留上一版备份。
- 使用文件字节的 SHA-256 token 检测外部修改；不自动覆盖不同版本。
- 文档 ID 必须是规范 UUID，阻止路径穿越；白板目录/文件不允许符号链接。
- 单文件限制 64 MB，超限显示失败，当前画布仍保留，可导出备份。
- 列表中损坏或不兼容文件会跳过并提示，原文件不删除。
- 已支持 GitHub 后台同步和冲突副本保留，详见《实现记录》。此版本没有实时多人协作、回收站或工具素材库的独立持久化。Excalidraw 素材库不作为已保存白板文档的一部分。

## 浏览器预览

浏览器使用 IndexedDB 保留白板 JSON，并显示“已保存到浏览器”。它与桌面工作目录互相独立，不冒充原生文件存储。可以通过“导出 JSON”下载文档文件。存在未完成保存时，离开页面会触发浏览器的离开确认保护。

## 验证记录

- TypeScript、Vite 与 macOS Apple Silicon 桌面调试包构建成功。
- 9 项 Rust 测试通过（原有 6 项 + 白板 3 项），覆盖白板创建、场景及图片数据往返、常用元数据、目录迁移后重新打开、并发/外部修改拦截、路径穿越及损坏文件跳过。
- 浏览器手动验证：创建两份独立白板、矩形绘制、重命名、设为常用后的分组去重、切换恢复、刷新后恢复图形与元数据。没有发现浏览器控制台错误。
- 依赖安装后对 Excalidraw 的旧版 nanoid/lodash-es 传递依赖进行兼容版本覆盖，npm audit 为 0 项漏洞；Excalidraw 已在 React 19 中完成实际绘图验证。
- 当前未获电脑控制权限，原生 WebView 内的点击、文件选择与退出流程尚未实机验收；文件服务通过 Rust 测试验证。Windows/Linux 未实机验证。
