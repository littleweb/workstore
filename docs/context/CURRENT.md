# 当前开发上下文

更新日期：2026-09-18。

## 当前基线

应用版本 0.1.4；稳定发布仓库为 littleweb/workstore。此前仓库主要托管安装包，本次首次导入完整源码、测试、模板、开发文档和跨设备交接规则。请以实际 Git 分支和提交为准。

容器、文档、Excalidraw 白板、小漫画、全局 AI、可选 GitHub 数据同步和应用内更新已实现。项目管理仍为开发中。Mac Apple Silicon 已构建和发布；其他平台尚未实机验收。

## 最近完成的行为

- Codex 在启动时后台检测、保存设备配置，保留用户选择的其他 API provider。
- 最近工具切换不重排，新加入排在前面；文档/白板/漫画切换不再反复写打开时间。
- GitHub 上已有导航结构和漫画文件。曾出现另一台设备因 shallow.lock 残留无法拉取，已改为重建独立缓存并保留旧缓存和本地文件。
- Git fetch 曾受 45 秒统一超时和桌面缺失系统代理影响。0.1.4 自动继承系统代理，fetch/push 300 秒，ls-remote 60 秒，超时清理 Git 进程树。
- 列表刷新失败会保留路径并补试；无变化同步也刷新列表，单个工具失败不阻断其他工具。

## 验证与限制

最近功能验证包含双设备新建/拉取/合并、最近列表与漫画读取、Git 锁恢复、真实公开 GitHub fetch、AI 文本实测、前端测试及 macOS 桌面构建。联网/模型测试默认忽略，不应为了普通文档修改反复执行。

macOS 安装包目前为 ad-hoc 签名，未做 Apple 公证。更新签名已配置，私钥不在仓库。Windows/Linux 的构建和交互仍需各平台验证。网络故障无法仅通过延长超时解决，目标设备须能访问 GitHub。
