# 小漫画第一版开发交付

日期：2026-09-16。设计依据见 `docs/designs/comics-v1/README.md`；原方案保留作为设计记录，本文件描述当前代码和实际验证范围。

## 已实现

- WorkStore 工具入口与列表布局；创建、爆款示例、作品编辑、作品设定、历史、发布物料页面。
- 六套原创策划、AI 绘制的内置模板，共 32 张完整示例分镜，支持完整预览与复制为作品。4/6/8 张有独立剧情节拍，3:4、1:1、4:3 为输出比例。
- 底部无内边框多行主题输入，同排模板和规格，发送图标；手动选择的张数在换模板时保留。
- 创建后保存草稿，通用 AI 编排故事并顺序绘图；单张重绘、文字修改、整篇与关联页面调整。图片请求携带主参考、前页、实体参考及整篇状态，支持停止和失败重试。参考图约束不是对 AI 画面一致性的绝对保证，最终仍应查看结果。
- React Flow 单行横向画布，卡片选择后才显示右栏；中间三个标签和右侧发布入口。
- 作品设定含角色、场景、道具、参考图和锁定项；历史快照与恢复，迟到图片保留为历史候选，不替换已修改画面。
- 小红书、抖音、视频号分别保存本地发布草稿。整组生成封面与文案、单项重生成、手动编辑、封面标题独立、图片排序、过期提醒、复制与 ZIP 导出。此功能不向平台直接发帖。
- `.comic.json` 独立文件、原子保存、内容校验、并发修改冲突保护、备份及 WorkStore 同步。图片以 SHA-256 去重，历史仅存引用。

## AI 接入

没有另接服务，也没有改变用户的全局供应商。通过原有 `src/ai/client.ts` / `src-tauri/src/ai.rs` 通用网关扩展图片请求：

- `ai.generate({toolId:'app.comic', messages, image:true, references})`；沿用 Codex 登录、全局模型、代理、并发、超时及取消。
- `ai.capabilities()` 提供适配器能力。默认 Codex 的内置 imagegen 已实际验证；OpenAI-compatible 的现有文本适配器不会假装支持生图。
- 只读取新任务 UUID 对应的 Codex 图像目录，不相信回答里任意文件路径。PNG 验证后存入 `data/ai-images/<hash>.png`。
- 单张修改是参考图引导的重绘，不是像素级局部编辑。文字为独立字幕层，导出按目标比例留白排版，不拉伸原图。

## 公共模板与技能

- 源目录：`public/comics/templates.json`；协议：`schemas/comic-template.schema.json`。
- 公共包：`content/comics/catalog.json`、`content/comics/templates/<id>/<revision>.json`。包内图片按哈希去重，保留旧修订；新 ID 追加。
- 桌面创建页“更新模板”匿名读取 `littleweb/workstore` 的 main 提交，再以固定提交下载包，检查路径、大小、哈希和业务 schema。验证后才激活缓存。无网、404、坏包时内置模板及现有作品仍可用。
- 模板缓存与私人工作区同步分离；作品保存自己的模板快照。被采用的公共图片使用工作区内的内容地址保存。
- “爆款作品”目前固定使用六套内置示例，`feedConfig` 的 mode / endpoint / enabled 已预留，线上数据未启用。
- `skills/comic-template-maker/SKILL.md` 为“小漫画模板制作”，同时已放入本机 `~/.codex/skills/comic-template-maker`。可从完整作品提取角色、场景、画风、节拍和连续性资料，再校验、打包。需要新会话重新读取技能列表时才会出现。
- 公共包已在本地准备完成，**尚未推送公共仓库**。当前工作目录无 Git 元数据；动态拉取的线上完整链路须在目录正式发布后验收。未上传任何用户作品或密钥。

开发命令：

```bash
python3 scripts/comics/create-seeds.py
node scripts/comics/pack-templates.mjs
node scripts/comics/pack-templates.mjs path/to/new-template.json
node --test tests/*.test.mjs
cargo test --manifest-path src-tauri/Cargo.toml
```

`predev/prebuild` 自动生成模板校验器，桌面端无需运行时 eval，不放宽 CSP。

## 保存错误修复

补齐工作台状态校验中的 `app.comic` 工具编号，修复进入小漫画后出现“保存失败：工具记录无效或重复”。新增回归测试从前端工具注册表读取全部编号，验证真实保存与重新打开；重复编号和未知工具仍会被拒绝。此修复无需清空或重建工作区。

## 最近打开记录修复

打开工具时立即写入最近打开记录，成功保存后再进入工具；失败时明确提示，避免仅在内存中显示成功。默认收藏固定为 AI、项目和文档，不再随着工具注册顺序改变。已有收藏设置保留，收藏工具仍只显示在常用区。

本机排查时磁盘已有未收藏的 `app.comic` 打开记录。新增真实存储回归测试，验证未收藏的小漫画记录经过连续关闭、重新打开和时间更新后仍保留，全部 12 项存储测试通过。未修改用户工作区数据。

- 默认精选作品从 6 部增至 12 部；新增 6 部原创四格完整插画，支持搜索和完整预览。创建模板仍是 6 个，远程精选数据源开关保留。新增资源和生成提示见 `docs/designs/comics-v1/featured-prompts.md`，使用内置 image_gen 生成并已复制到 `public/comics/`。
- 原比例参考图绘制改为 SVG 裁切视窗，避免横向缩略图拉伸角色。

## 第三轮创作流程调整（2026-09-16）

- 任务进度固定在右下角，保留停止按钮。
- 「作品设定」改为第一项「制作故事」。新建作品先编写故事，再逐个生成角色、场景与道具参考图；每个结果即时入位并保存，点击已完成图片可放大。失败或中断后可继续制作；打开资产未完成的作品时进入制作故事页。
- 故事与资产就绪后自动切到漫画编辑并开始绘图。用户已切换到另一作品时不抢回当前作品。
- 漫画对白使用画内 SVG 卡通气泡，编辑器、历史预览、示例预览、PNG/发布包导出保持相同排版。画面底部不再显示对白，AI 绘图预留气泡区域且不直接绘制文字，避免重复文字。
- 模板增加可选 `dialogueStyle`（shape: speech/thought；position: top/bottom；fill: white/cream）。原六模板已追加 revision 2 公共数据包，保留 revision 1；旧作品/模板缺字段时使用默认气泡。数据包仅在本地准备，未上传仓库。
- 发布页在用户点击生成时才调用 AI；无草稿时不自动填入封面和标题，不以进入发布页触发生成。
- 爆款封面统一完整适配，加独立裁切边界，修复第 2、3、4 项等作品上下被裁切及相邻格子露边。

验证：29 项 JavaScript 自动测试通过。隔离浏览器完整验证制作故事首屏、分步资产填充、资产放大、右下任务栏、自动编辑切页、画内气泡、发布点击前零 AI 请求、点击后生成、PNG 气泡导出、封面完整显示。AI 调用使用模拟响应；本轮未额外运行整篇真实生成。截图见 `docs/designs/comics-v3-implemented/`。

## 第四轮：对白融入原画

替代第三轮的 SVG 对白叠加方案。对白随图片由 WorkStore 默认 AI 一体绘制，提示词要求按人物视线、发声关系、情绪与自然留白设计手绘字体和气泡，避开脸、手、关键动作与道具，不固定顶部/底部横条。编辑、历史和导出不再补画对白。

页面记录 `imageDialogue` 以识别图片对应的台词。修改对白使页面回到待绘制状态，使用「应用对白并重绘」更新图像；生成期间台词发生变化则结果作为历史候选保留，不覆盖新修改。旧画面需重绘以使用新方案，尚未融入对白的图片禁止直接导出以防静默丢字。

模板 `dialogueStyle` 增加 integrated 渲染模式与 lettering 美术指导，position 使用 auto；本地公共模板追加 revision 3，保留既有版本，未推送远程。

33 项自动测试通过，客户端 debug 构建通过。浏览器采用模拟 AI 验证调用、取消叠加、导出不加文字等机械流程；本轮未使用真实服务重新生成样张，实际字形质量、文字准确度与主体避让仍需真实图片验收。
