# Notion Style

Minimalist hand-drawn line art, intellectual aesthetic.

## Element Combination

```yaml
canvas:
  ratio: portrait-3-4
  grid: single | dual

image_effects:
  cutout: clean
  stroke: none | white-solid
  filter: none | muted-tones

typography:
  decorated: none | handwritten
  tags: black-white | pill
  direction: horizontal

decorations:
  emphasis: circle-mark | underline
  background: solid-white | paper-texture
  doodles: hand-drawn-lines | arrows-curvy
  frames: none | rounded-rect
```

## Visual concept
四个自上而下相连的简洁步骤，分别有书本、说话气泡、问号、灯泡线稿，手绘弧形箭头。不要新增文字。

All lettering must be native hand-drawn-style Chinese, sharp and readable. No logos, watermarks or extra text. Leave safe margins of 7% and bottom 10%. Keep conceptual labels accurate, no photorealism. Use the supplied first card only as visual style/palette/character reference; create this distinct next card and do not copy its title or content.
