# AI设计室参考素材

封面和作品示例来自用户指定的 https://yunshu.quantv.com/image-creation ，用于本工具功能导航与示例。2026-10-03 通过已登录的 Chrome 保存当前页面完整 MHTML 快照，逐页验证功能标题和页面地址，读取每个 `.gal-card` 的真实边界、顺序、原图/AI作品标签和完整提示词；不根据相邻文件名或下载顺序推断配对。

101 个功能共 479 组示例：453 组原图/AI作品对照、26 组单图，共 932 个图片位置、917 个不同图片文件。宽窗口每行两组，对照图片位于同一张卡片内；单图示例保留其原有形式。点击图片查看完整大图，有提示词的卡片可复制完整文字。功能目录采用五列，我的作品采用四列布局。

`sources.json` 的 `examplePages` 记录每页标题、页面地址、采集时间、组数、组序号、图片顺序/标签/地址及提示词摘要校验值；`exampleAssets` 记录原站图片地址、本地路径、原尺寸、字节数和 SHA-256。图片使用原站 CDN 的 WebP 格式转换地址，没有缩略尺寸参数，不再使用截图切片。保留源分辨率，参考源本身较小的图片不会凭空提高清晰度。封面保留原尺寸编码 WebP。

这些图片不是用户生成的作品，也不作为生成时的默认参考图。用户上传图片和生成结果存放于用户工作区，不写入源码目录。分类、标题、说明和已采集字段存放在src/design-studio/catalog.json，生成使用WorkStore统一AI接口和自己的任务提示词，不调用参考站的生成接口。
